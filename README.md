# Delivery Time Prediction using Linear Regression

## Project Overview

This project develops a **Linear Regression model** to predict delivery time based on historical delivery data. The objective is to identify the factors influencing delivery duration and build a predictive model that supports operational planning and logistics optimization.

The project demonstrates the complete machine learning workflow, including data preprocessing, exploratory data analysis, feature engineering, model development, and performance evaluation.

---

## Business Objectives

- Predict delivery time using historical delivery data.
- Identify the key factors affecting delivery duration.
- Improve delivery planning and operational efficiency.
- Support data-driven decision-making for logistics management.
